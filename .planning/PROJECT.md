# PROJECT.md

## Project Vision
Build a kahoot-like game, where one host defines the questions and multiple players connect at the same time.

## Target Users
General public, groups of friends or colleagues.

## Key Features
- One person hosts and defines questions/answers
- Generates a pin code for room connection
- Players join the correct room with the pin
- Scoreboard at the end of the game
- Host can reconnect to the room
- Waiting period before the game starts for player connection
- All players in the room can see who else is connected

## Constraints
- Must use Next.js
- Prepare to run on Vercel
- Can use Supabase or Prisma Postgres
- No timeline constraint
